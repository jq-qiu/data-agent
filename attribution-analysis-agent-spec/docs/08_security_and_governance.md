# 安全与治理详细设计

## 1 安全目标

归因分析系统能够访问数据库、附件和可选命令运行环境，风险明显高于普通聊天系统。安全设计遵循零信任输入、最小权限、确定性策略先于模型判断、默认拒绝、全程可审计五项原则。大模型可以提出工具调用建议，但无权自行扩大数据源、文件路径、命令或网络权限。

安全边界包括浏览器、API 服务、任务 Worker、模型服务、企业数据源、文件或对象存储和命令沙箱。用户问题、附件正文、数据库内容和外部检索结果均视为不可信数据，其中出现的“忽略系统规则”“执行命令”等文本不得被当作系统指令。

## 2 威胁模型

| 威胁 | 示例 | 核心控制 |
|---|---|---|
| 越权访问 | 修改 ID 下载他人附件 | 每次查询都带 `user_id` 归属条件，未授权统一返回 404 |
| SQL 注入或破坏 | 模型生成 `DROP TABLE`、多语句、耗时笛卡尔积 | AST 白名单、只读账号、成本和超时限制 |
| 路径穿越 | 文件名为 `../../secret.env` | 服务端对象键、路径规范化、根目录归属校验 |
| 恶意附件 | 宏、脚本、压缩炸弹、解析器漏洞 | 类型嗅探、大小与展开率限制、扫描和隔离解析 |
| 命令注入 | 将用户问题拼入 shell 字符串 | 默认关闭、参数数组、命令与参数 Schema 白名单、无 shell |
| Prompt 注入 | 附件要求泄露系统 Prompt 或调用危险工具 | 内容分区、指令优先级、工具策略网关、输出检查 |
| 数据外泄 | 把整张客户表发给模型或日志系统 | 列白名单、脱敏、行数限制、数据最小化、出站控制 |
| 重放与劫持 | 复用 WebSocket token | 60 秒、单次消费、绑定用户和会话、仅存摘要 |
| 配置投毒 | 热更新扩大命令权限 | 管理员 RBAC、Schema 校验、差异审计、版本回滚 |
| 资源耗尽 | 大附件、无限 Agent 循环、慢 SQL | 配额、超时、并发上限、最大迭代、取消令牌 |

## 3 身份认证与授权

### 3.1 认证

- 对接认证中心时使用 Authorization Code + PKCE，严格校验 `state`、issuer、audience、签名、过期时间和 nonce。
- Cookie 设置 `HttpOnly`、`Secure`、`SameSite=Lax`，登录后轮换会话 ID；敏感 POST 使用 CSRF Token 或严格 SameSite + Origin 校验。
- 用户被禁用后，API 和 WebSocket 在下次校验时立即拒绝，不仅依赖前端隐藏按钮。
- 管理员账号启用更短会话和强认证策略，生产环境建议要求多因素认证。

### 3.2 授权矩阵

| 能力 | 分析用户 | 系统管理员 |
|---|---:|---:|
| 管理自己的会话、附件、任务、结果 | 允许 | 允许自己的资源 |
| 查询企业数据源中的授权数据 | 按数据源与行列策略 | 按业务授权，不因 admin 自动获得全部数据 |
| 查看脱敏运行状态 | 自己的任务 | 全局 |
| 查看详细审计日志 | 禁止 | 允许 |
| 重载非密钥配置 | 禁止 | 允许 |
| 修改密钥、数据库凭据 | 禁止 | 通过外部密钥管理流程，不走热更新 API |

管理员是系统运维角色，不应自动绕过业务数据权限。数据源连接应绑定服务账号和允许的 Schema，必要时结合数据库行级安全或在查询网关注入组织过滤条件。

## 4 SQL 工具安全

SQL 工具必须经过以下固定流水线，任何一步拒绝都不得执行：

```text
模型输出结构化查询意图
  → 单语句解析为 AST
  → 只读语句及节点白名单
  → Schema 表列与函数白名单
  → 强制权限过滤和参数化
  → 行数 超时 成本限制
  → EXPLAIN 风险检查
  → 只读事务执行
  → 结果行列脱敏和截断
  → 写入证据引用与审计摘要
```

### 4.1 语法和语义限制

- 仅允许单条 `SELECT` 或以 `WITH` 开始且最终为 `SELECT` 的查询；`EXPLAIN SELECT` 只由系统内部生成。
- 拒绝 `INSERT`、`UPDATE`、`DELETE`、`MERGE`、`DROP`、`ALTER`、`CREATE`、`TRUNCATE`、`CALL`、`LOAD DATA`、`INTO OUTFILE`、`SELECT ... FOR UPDATE`、多语句和事务控制。
- 使用 AST 解析器判断，不能用正则表达式替代；解析失败即拒绝。
- 表、列、函数必须存在于当前数据源的授权语义层。禁止访问 `information_schema`、系统库、凭据表和未登记对象。
- 用户值使用绑定参数，不将自然语言值直接拼进 SQL。标识符只能从已验证元数据映射得到。
- JOIN 必须具备已登记关系或显式批准的连接键；检测无条件 JOIN、异常多对多和粒度放大风险。

### 4.2 运行限制

- 使用专用只读数据库账户，数据库侧撤销写入和 DDL 权限。
- 设置查询超时、最大扫描量或成本、最大返回行数、最大列数和并发数。默认结果行数建议 1,000，分析聚合查询优先返回更小结果。
- 执行前进行 `EXPLAIN`；全表扫描不必一律拒绝，但超过配置成本或缺少必要分区过滤时拒绝或要求澄清。
- 在独立连接和只读事务执行，取消时调用数据库驱动 cancel；超时后强制回收连接。
- 原始行仅在 Worker 内存和受控临时区短暂存在。发送给模型前按字段分类做脱敏、聚合和采样。

### 4.3 数据结果治理

- 敏感列按 `public/internal/confidential/restricted` 分类；restricted 默认不进入模型上下文。
- 手机、身份证、地址、邮箱等按业务规则掩码；禁止在日志和 WebSocket 工具摘要中出现完整值。
- 证据记录保存数据源、查询摘要、口径版本、时间范围、结果摘要和可校验哈希，不保存整张明细。
- 结论中的每个关键数字必须绑定证据 ID；数字一致性校验失败时不得发布最终报告。

## 5 文件与附件安全

### 5.1 存储规则

- 用户文件名只作为元数据展示，实际对象键由服务端使用 `user_id/conversation_id/attachment_id` 生成。
- 所有路径通过 `resolve/canonicalize` 后校验仍位于预期根目录；拒绝绝对路径、`..`、NTFS Alternate Data Stream、设备名、符号链接和 reparse point 越界。
- 文件创建采用不可预测名称和排他创建，临时文件校验成功后原子移动。目录权限只授予服务账号。
- 下载始终通过鉴权接口或短时签名 URL，不直接暴露本地路径。

### 5.2 上传和解析

- 同时校验扩展名、Content-Type 和文件魔数；以服务端嗅探结果为准。
- 配置单文件大小、单会话总量、每日配额、压缩包层数、解压后总大小和压缩比。
- Office 文件禁用宏执行和外部链接；PDF、图片及文本解析在低权限隔离进程中运行，不允许网络访问。
- 解析器设置 CPU、内存、时间和页数限制；解析失败只记录安全摘要。
- 允许类型按业务最小化，例如 `pdf/docx/xlsx/csv/txt/md/png/jpeg`。若无必要，不接受可执行文件、脚本和任意压缩包。
- 解析文本标注来源和不可信边界，不能覆盖系统 Prompt 或工具策略。

### 5.3 文件工具

- 文件工具只能访问当前会话的 `uploads`、`workspace`、`exports` 逻辑根；不同会话绝不共享工作目录。
- 只提供高层操作，如读取已授权附件、写入指定导出、列出当前会话文件，避免开放任意 `open(path)`。
- 导出文件先写临时文件，完成后计算哈希并原子发布；报告中的公式注入、CSV 公式和 HTML 脚本必须转义。

## 6 命令执行安全

命令执行功能默认关闭。若某个确定业务场景必须启用，应满足全部条件：

1. 仅允许管理员配置的工具 ID，例如 `render_report`、`convert_document`，模型不能直接提供可执行文件路径。
2. 每个工具都有固定可执行文件、参数 JSON Schema 和参数到 argv 的安全映射；使用 `shell=false`，禁止字符串拼接、管道、重定向、变量展开和命令替换。
3. 子进程运行在容器或受限沙箱，使用非特权用户、只读根文件系统、当前会话工作目录、最小环境变量、无宿主机挂载。
4. 默认关闭网络；确需访问时只允许明确域名和端口。禁止访问云元数据地址和内网管理网段。
5. 设置 wall time、CPU、内存、进程数、输出大小和文件系统配额；取消任务时终止整个进程树。
6. 不向命令环境注入模型 API Key、数据库密码或用户访问令牌。
7. 审计工具 ID、参数摘要、镜像版本、开始结束时间、退出码和产物哈希；标准输出先脱敏再保存摘要。

任何“万能终端”“任意 Python”“任意 shell”都不属于生产功能范围。

## 7 LLM 与 Prompt 注入防护

- System Prompt、工具定义、策略配置和业务内容使用结构化消息分离；检索文本前后增加“不可信证据”边界。
- 模型无权决定自己是否通过安全检查。SQL、文件、命令和导出均由独立策略网关进行确定性校验。
- 不把密钥、完整系统 Prompt、连接串或内部错误栈放入模型上下文。
- 工具返回使用严格数据模型解析，拒绝模型伪造的“工具成功”文本；只有运行时签发的 `tool_call_id` 可成为证据引用。
- 对“忽略规则、泄露 Prompt、读取其他会话、执行系统命令”等攻击建立固定红队样例并进入发布 Gate。
- 输出 Markdown/HTML 在前端进行白名单清洗，链接使用安全协议，禁止内联脚本和危险 URI。

## 8 WebSocket 与 API 安全

- TLS 是生产必需；反向代理和应用都限制请求体与帧大小。
- WebSocket token 具备至少 128 位熵、60 秒有效、单次使用、绑定用户和会话；数据库仅存摘要。
- 校验 `Origin`，限制连接数、消息频率、任务频率和每日模型预算。
- URL、代理日志、APM 和错误跟踪系统对 token、Cookie、Authorization、签名 URL 自动脱敏。
- 事件只含用户可见的阶段摘要，不传隐藏思维链。工具输入输出以安全摘要替代原文。
- 所有改变状态的 HTTP 操作执行 CSRF 和幂等检查；批量删除设置数量上限。

## 9 密钥与配置治理

- 密钥保存在云密钥管理、Vault、容器 Secret 或操作系统凭据存储中，禁止进入 Git、`system_configs`、日志和前端配置。
- 配置分为可热更新和仅启动加载两类。模型温度、最大迭代、工具超时等可热更新；密钥、数据源根证书、命令白名单根策略只能通过受控发布或密钥轮换修改。
- `/api/admin/reload` 必须校验管理员、`expected_version`、配置 Schema、范围和依赖健康，记录脱敏 diff。失败时旧版本继续服务。
- 每个任务保存 `config_version`；报告和审计可还原当时使用的模型、Prompt 版本、指标口径版本和工具策略版本。
- 至少保留上一有效快照以快速回滚。回滚也需授权、审计和验证。

## 10 日志 审计与隐私

### 10.1 必记事件

- 登录成功和失败、角色或用户状态变化。
- 会话、附件、任务、结果的创建、下载、删除和越权拒绝。
- 工具授权、拒绝、开始、结束、取消和超时。
- 配置验证、重载、失败和回滚。
- SQL 安全拒绝、命令安全拒绝、Prompt 注入检测和频率限制。

### 10.2 禁止记录

- 密码、访问令牌、Cookie、API Key、完整连接串。
- 未脱敏个人信息、完整附件正文、完整 SQL 查询结果。
- 模型隐藏推理和系统 Prompt。

日志结构至少包含 `timestamp/request_id/trace_id/user_id/resource_id/action/result/error_code/config_version`。日志存储设置访问控制、防篡改和保留期；管理员查看详细日志本身也产生审计记录。

## 11 数据生命周期与删除

- 会话删除前处理活动任务，随后清理数据库子记录与三个会话目录。路径校验或文件删除失败时保留 `deleted` 隔离状态并补偿重试。
- WebSocket 令牌消费或过期后 24 小时内清理；任务工作区在终态后按策略清理。
- 备份也必须纳入到期删除和恢复权限策略。删除请求无法即时影响离线备份时，应记录预计过期窗口。
- 导出文件带短时下载授权；公开分享不在 MVP 范围。

## 12 安全测试与上线门禁

下列任一项失败即阻断发布：

- 普通用户可通过 IDOR 读取或删除他人资源。
- SQL 工具可执行写入、DDL、多语句、系统库访问或绕过行列权限。
- 路径穿越、符号链接或压缩炸弹测试成功逃逸沙箱。
- 命令工具可执行未登记程序、使用 shell 元字符或访问非授权网络。
- WebSocket token 可重放、长期有效或绑定会话失效。
- 日志或事件中出现测试密钥、完整 PII 或隐藏 Prompt。
- 配置校验失败后仍部分生效，或运行中任务中途切换版本。

安全问题按严重性设定修复时限；高危事件立即禁用相关工具、轮换受影响凭据、保全审计记录并启动影响范围分析。
